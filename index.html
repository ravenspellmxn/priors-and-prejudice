05Results

Run 2,000 mice

Pull the lever to run 2,000 simulated mice through three situations. Each burette reads the median trials until 90% sure.

Why so slow?

One mouse: 19 trials of 80/20, then the block flips to 20/80.

What you just saw draftAfter a long biased block it's so sure that the opposite block seems almost impossible. It passes through "unbiased" first, so relearning takes far longer.

06Takeaway

draft · Raven's takeaway goes hereA Bayesian observer learns a biased block in about 8 trials but needs far longer after a reversal, so block lengths should leave room for relearning.
